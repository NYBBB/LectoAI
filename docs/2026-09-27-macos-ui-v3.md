# LectoAI Mac 界面与交互 v3（2026-09-27）

> 状态：U4 已实现（0.3.0）。文中的“主设计”指早期的内部设计稿，未随仓库公开；本文取代其中主窗口、浮动卡片与控件布局的部分。
> 背景：0.2.2 Demo 试用后，布局、按钮、交互逻辑、小窗和翻译呈现整体重做：从每个按钮的用途重新想。

## 1. 先想清楚：课上到底在做什么

一堂课里，学生绝大部分时间只是在**看字幕**。其余操作少而关键：

1. 走神或没听懂 → 想一键标出来，或者马上问一句；
2. 老师强调重点 → 标一下，偶尔记一句自己的话；
3. 回过神来 → 看一眼“现在讲到哪了”。

课后要做的是：找到这堂课、回听某一处、把文件放进课程文件夹。

另一个事实：课上 Mac 屏幕通常还要放课件或笔记。**小窗是课上的主界面之一，不是附属品。**

据此，三个界面各司其职：

| 界面 | 职责 | 不承担 |
|---|---|---|
| 主窗口 | 完整阅读、记笔记、问 AI、课后回看与导出、课堂记录 | — |
| 小窗 | 盖在任何 App（含全屏）上的滚动字幕，外加录音状态、标记、记一笔 | 设置、历史、长对话 |
| 菜单栏 | 录音状态与开始/暂停/结束的兜底入口 | 阅读 |

## 3. 翻译的呈现（用户点名的问题）

**0.2.2 的做法**：每句先出逐句译文；一段结束（停顿 5 秒、满 8 句或 90 秒）后整段重译；界面随即隐藏这段每一句的译文，把整段译文作为新方块放到段末。用户看到的是“前面的翻译全没了，后面冒出一大段”。表达单位在句子和段落之间来回切换，是问题根源。

**v3 规则**：

1. **段落是唯一的阅读单位**。英文按段落连续排版；中文紧跟在同一段英文下面，同样连续排版。原文、双语、中文三种模式都用同一套段落。
2. **中文先草稿，后原位升级**。段落进行中，每句译好就接到这段中文的末尾（草稿）；段落结束后得到整段译文，**在同一位置**替换这段中文，用短暂淡入过渡。前面的文字不会消失，也不会换位置；用户只会看到这段中文变得更通顺。
3. **进行中的段落**：英文稳定文字后面接浅色的临时识别文字，定稿后原地变深；中文末尾用“…”表示还有句子在翻译。临时文字接在当前段还是另起一段，按它的估计开口时间套用同一分段规则判断（实测：只看当前时刻会让长句先单列再并回；只看识别起点会把停顿后的新段接到旧段），定稿前后段落位置保持不变。
4. **没有译文时不留空**：中文模式下，历史课堂没有译文的句子以浅色英文兜底，并提示可以翻译；进行中的句子只显示“…”。
5. **临时译文（实测后修订）**：原计划临时识别文字不翻译。用合成讲课音频实测发现，老师一口气说长句时系统要等停顿才出定稿，中文模式会十几秒只有“…”。因此录音中的临时文字约每 1.5 秒（至少 3 个词）翻译一次，以淡色显示在这段中文末尾；定稿并译好后由正式译文取代。淡色表明它还会变化，已定稿的中文不会跳动。

内部数据不变：逐句译文和整段译文照常保存（批注引用、导出仍可用）；只改变呈现。

### 4.1 工具栏（每个控件的用途）

| 控件 | 用途 | 状态与行为 |
|---|---|---|
| 侧栏开关 | 需要更多阅读空间时收起课堂记录 | 系统标准，⌃⌘S |
| 标题（课堂名 ▾） | 告诉用户正在看哪堂课；标题菜单里重命名、在 Finder 中显示 | 副标题：日期时间 · 时长 |
| 开始听课 ▾ | 全窗口唯一的主操作；下拉选择“麦克风（现场上课）/电脑声音（网课）” | 缺少识别资源时自动准备后再开始，按钮显示进度 |
| 录音状态 | 让用户确信正在录、录到了声音 | 红点 + 计时 + 真实输入电平；暂停显示“已暂停” |
| 暂停 / 继续 | 课间休息 | 暂停后仍是同一堂课；暂停时可换音源 |
| 结束 | 保存并收尾 | 结束后原地进入回看，显示已保存/导出结果 |
| 原文 / 双语 / 中文 | 选择阅读语言 | 主窗口与小窗各自记忆；⌥⌘1/2/3 |
| 小窗 | 显示/隐藏字幕小窗 | 开关状态与小窗同步；⌘⇧F |
| AI 助手 | 显示/隐藏右侧助手 | 未连接 AI 时默认收起；⌥⌘0 |
| 导出（回看时） | 把这堂课的文件放进课程文件夹 | 已设置课程文件夹时一步导出；否则选择文件夹 |

导入录音、补识别等进行中的任务替换录音状态位置，显示进度和“停止”。

### 4.2 字幕区

- 段落排版，正文限宽约 760pt 居中，保证行长可读；字号 ⌘+/⌘− 调整。
- 左侧时间只标段落开头；进行中的段落用红点标出。
- 悬停段落时，左侧时间下方出现“记笔记 / 问 AI”（放在右上角会挡住正文，已改位）；右键菜单另有复制、从这里播放。
- 回看时点击任一句子，从该句开始播放；播放中的句子高亮，视图跟随。
- 自动跟随最新内容；用户向上滚动即停止跟随，出现“回到最新”；滚回底部自动恢复。
- 疑似识别异常的句子淡化显示，不再插入警告文字。
- 识别缺口在时间线对应位置显示：“这段没有识别出文字，录音已保存 · 补识别”。

### 4.3 记一笔与标记（课上）

- 底部常驻一条输入栏（仅在录音或暂停时）：
  - **没听懂**（⌘⇧U）、**重点**（⌘⇧I）：一键标记当前时刻，不需要打字；出现“已标记 · 撤销”提示。
  - **记一笔**（⌘⇧N 聚焦）：开始输入时锁定时刻（输入框前显示时间），回车保存；字幕继续滚动，不打断阅读。
- 标记和笔记显示在对应段落下方，一行一条：图标、时间、文字；点击可补写或修改，悬停可删除（可撤销）。
- 没听懂的标记是 AI 助手“解释我没听懂的地方”的输入；标记只代表用户的判断，不改写为老师的说法（主设计 §2.8 来源规则）。

### 4.4 课后回看

- 底部输入栏换成播放条：播放/暂停、进度、当前时间、倍速。
- 结束后顶部显示一次“已保存 · 时长 · 已导出到〈文件夹〉/导出…”；翻译收尾、补识别等后台任务在同一处显示进度。
- 回看时在段落上“记笔记”：先出现输入框，写了内容才保存；空着按 Esc 不留下空记录。

### 4.5 AI 助手：课堂纪要（右侧，默认打开，0.3.1 重做）

用户反馈：同传有时不适合看，希望直接看实时总结的重点；旧网页里“话题卡 / 重点 / 洞察卡 / 全文总结”四套东西互相重叠，且重点每次整体覆盖、前面的会丢。0.3.1 把它们合成一套“课堂纪要”，只回答两个问题：

1. **此刻在讲什么**（顶部“此刻”卡）：当前话题、阶段（定义/举例/推导/问答/过渡/回顾/课程安排）、一句给学生的提示，每次整理后替换。回看时显示为“最后在讲”。
2. **这堂课讲了什么**（纪要时间线）：按话题分节，每节一个标题、时间范围、一句概述、不超过 8 条要点；要点带类型标签（概念 / 重点 / 例子 / 提醒）和出处时间，点击跳回原文。最新一节标“更新中”，课上持续续写；换话题后固定，前面的内容不再被覆盖。“提醒”只在老师明确说到考试、作业、截止时间时出现。

- 你的提问按提问时的课堂时间插在纪要时间线里（课后提问放在最后），不再另起一块。
- 整理节奏：课中约每 2 分钟且有 10 句以上新内容时自动整理一次，暂停和结束时再补一次；右上角 ↻ 立即整理。每次只把“当前小节 + 之后的新原文”交给 AI，请求大小有上限；纪要整理与问答分开两条请求通道，整理时照样能提问。每堂课最多 60 次 AI 请求。
- 术语第一次出现附英文原词，便于和老师的原话、课件对上；只依据原文，不补充老师没讲的内容。系统提示词写在核心 `LectureDigest.systemPrompt`，后续用真实课堂再调。
- 自动整理的开关在助手“⋯”菜单和设置 → AI 助手；整理失败（如密钥和服务地址不匹配）在“此刻”下方直接写明原因。
- 助手默认打开，三栏布局保持平衡；未连接 AI 时显示连接卡片。旧记录中的“话题与重点”只读显示。

### 4.6 开始页（没有打开任何课堂时）

- 正中一个大的“开始听课”按钮，下方是音源选择。
- 准备清单：英语识别、中文翻译、AI 助手（可选）、课程文件夹（可选）。每项显示真实状态与一个动作（下载/准备/连接/选择），替代首次启动向导。
- 识别资源缺失时直接点开始也可以：App 自动准备，完成后开始；Apple 识别不可用时按主设计 §6.6 提示下载离线语音模型。
- 上次异常中断的课堂在这里提示“录音已保留 · 打开”。
- 次要入口：导入录音文件。

- 深色半透明面板（字幕惯例，叠在白色课件上也清楚），可调大小，位置和大小自动记忆；默认在屏幕下方居中。
- 最近两三段滚动显示，最新在底部；原文/双语/中文与字号独立于主窗口。
- 状态行常驻：录音红点与计时；有话题时跟一行话题。
- 悬停才出现控件：没听懂、重点、记一笔、暂停/继续、结束（二次确认）、图钉（置顶开关）、⋯（显示内容：原文/双语/中文/纪要；外观：深色/浅色；字号；打开主窗口；隐藏小窗）。
- “纪要”模式：显示最近一两节的标题与要点，底部一行是“此刻”的提示；同传不合适时看这个。
- 置顶（默认开）：浮在所有窗口和全屏 App 之上；关掉后像普通窗口一样可以被遮住。主窗口也可在“显示”菜单或设置里选择保持在最前（默认关）。
- 标记与记一笔在小窗内完成，**不激活 App、不把主窗口拉到前面**；记一笔时小窗临时接收键盘输入，回车保存、Esc 取消。
- 空闲时显示“开始听课”；已暂停时显示“继续”。
- 不能跨过系统安全界面；全屏覆盖以实际机器验证为准。

侧栏左下角：“新课堂”（回到开始页）与设置按钮。

### 6.1 AI 模型配置（A3，2026-09-29 设计）

AI 要承担课堂翻译后，调用频率和要求差别很大：翻译每段都要、必须快；问答次数少、要理解力强；课后整理不赶时间、要质量。因此改为“服务 → 默认模型 → 各功能覆盖”三层，功能单独设置时覆盖默认。

**三层结构**

1. **服务**：可保存多个（名称、服务地址、密钥）。密钥按服务分别存在钥匙串，保存后不再显示；已有的单个配置迁移为第一个服务。
2. **默认模型**：选一个服务 + 模型。所有功能默认用它。
3. **各功能**：每项可“跟随默认”或单独指定服务 + 模型；可单独开关（问答除外）。

| 功能 | 什么时候调用 | 频率 | 更看重 | 建议 |
|---|---|---|---|---|
| 课堂翻译（AI 理解后再翻，T1） | 每段讲完 | 高，约 30–45 秒一次 | 速度、稳定 | 快速便宜的模型 |
| 总结文章（主窗口“总结”，U9） | 每段讲完 | 高 | 忠实、中文通顺 | 快速或中档 |
| 纪要与此刻（右侧助手） | 约 2 分钟 | 中 | 结构化输出稳定 | 中档 |
| 问答 | 你提问时 | 低 | 理解力、首字快 | 较强的模型 |
| 课后整理（笔记整理、回看时整理纪要） | 手动 | 低 | 质量 | 最强的模型 |

## 7. 菜单与快捷键

| 菜单 | 项目 |
|---|---|
| 文件 | 导入录音… ⌘O；导出… ⌘⇧E；在 Finder 中显示 |
| 课堂 | 开始/暂停/继续 ⌘⇧R；结束并保存 ⌘⇧S；标记没听懂 ⌘⇧U；标记重点 ⌘⇧I；记一笔 ⌘⇧N |
| 显示 | 原文/双语/中文 ⌥⌘1/2/3；放大/缩小/默认字号 ⌘+/⌘−/⌘0；小窗 ⌘⇧F；AI 助手 ⌥⌘0 |

## 8. 本轮不做

- 多门课程：每门课各自的课程文件夹与命名（当前只有一个导出目录），以及按课表自动选择。
- 导入录音快于实时的识别（当前按 1 倍速导入）。
- 识别延迟提示、全局快捷键、小窗鼠标穿透、新界面英文文案（U5）。

## 9. 验收

- 构建通过；核心包测试覆盖段落呈现（草稿→整段原位升级、未译兜底、笔记与缺口归段）。
- 使用 Debug 演示数据（`--demo`）截图自查：开始页、上课中（主窗口 + 小窗）、回看、深色模式。
- 需要用户在真实课堂验证：长时间滚动流畅度、小窗在全屏课件上的显示与键盘输入、麦克风/电脑声音实际采集。
